# Visual direction

Canvas: 1920×1080. This cut uses the console palette: canvas `#F7F6F4`, white panels, ink `#232323`, brand orange `#E2773C`. Type is DM Sans, the same family as the app.

The mark is an orange square with a white lens. Captions are white plates with ink type.

The console scene still uses the product service colors for Compute, Data, Network, and Platform. Captions sit on an ink plate so they stay readable on the light field.
