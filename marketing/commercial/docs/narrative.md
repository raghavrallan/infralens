# Marketing narrative

A cloud estate is more than a bill. Cost, inventory, and Advisor can be seen, and someone still has to investigate, propose, and decide.

Flexera's 2025 State of the Cloud report is the outside evidence that managing spend is the top cloud challenge. It is not an Infralens result, and it is not the whole story.

Infralens is one product. The console holds a project-scoped estate snapshot. The agentic side works that same project: chat, workflows, findings, architecture, and approvals. There is no second suite and no second frontend.

Chat Agent mode runs a skill. Plan mode returns steps. The default scope is read-only, so the agent analyses and recommends and does not present a live change as already done.

Workflows enqueue a run when Azure or AWS is connected and the worker is up. Findings stay open with the gate and the recommended action. Architecture keeps a Solution Architect run and its delivery stage.

Approval records the decision. The inbox does not execute the change.

Close: see the estate, ask the agent, decide before you change it.
